## 5月16日：扩展评估

### 扩展指标评估 (evaluate_extended.py)
基于5折CV预测结果，补充AUC之外的7个评估维度：
- Decision Curve Analysis（净收益曲线）
- Risk Stratification（十分位风险分层）
- Precision-Recall 曲线
- ECE（Expected Calibration Error）
- PPV/NPV/LR+/LR-/风险梯度
- Risk Distribution（病例vs对照）
- ROC + Bootstrap CI

核心发现：
- 校准极好（ECE < 0.001）
- NPV > 99.5%（排除能力强）
- 风险梯度 17-29x（DM_full 高风险组6.41% vs 低风险组0.26%）
- AD_5yrs 几乎不可用（风险梯度仅3x，DCA无净收益）
- 模型定位：排除性筛查(rule-out) + 风险分层，非独立诊断工具

### 风险评分对比 (compare_risk_scores.py)
对比模型 vs CAIDE（无APOE）vs ANU-ADRI：
- 实现了CAIDE和ANU-ADRI的UKB数据计算
- 包含DeLong检验
- 全指标：AUC, Acc, Sens, Spec, Precision, F1, Brier

结果：
- CAIDE AUC 0.62-0.64（弱，特异性仅39%）
- ANU-ADRI AUC 0.69-0.72（中等）
- 我们的模型 AUC 0.82-0.84（除AD_5yrs 0.68）
- Brier校准优势10倍（0.018 vs 0.09-0.19）
- AD_5yrs：ANU-ADRI (0.720) 反超我们 (0.679)
- DeLong检验：CAIDE vs ANU-ADRI p<0.001

### 外部验证 (external_validation.py)
80/20 Hold-out验证（训练集401,792人，测试集100,449人，stratified split）
- 训练集：s01-s04 SFS选10个特征
- 测试集：独立评估模型+CAIDE+ANU-ADRI

结果：
- Hold-out AUC 与 5折CV 一致（DM_full: 0.829 vs 0.831），无过拟合
- 特征选择结果与CV版相似但略有不同（SFS受训练集影响）

### 论文特征对齐版 (run_aligned_pipeline.py)
匹配论文的138个可识别特征进行训练：
- 138特征 vs 1076全量特征，AUC仅差0.001
- 验证了特征选择的稳健性

### 选出的特征
CV版SFS（10个）：34-0.0, 400-0.0, 137-0.0, 2188-0.0_c1, 30710-0.0, 20110-0.4_pos, 1090-0.0, 6142-0.3_pos, 20023-0.0, 3526-0.0
Hold-out版SFS（10个）：34-0.0, 137-0.0, 400-0.0, 23112-0.0, 20023-0.0, 20110-0.4_pos, 3526-0.0, 1070-0.0, 30710-0.0, 30510-0.0
共同特征（7个）：34, 400, 137, 20023, 20110-0.4_pos, 3526, 30710

## 5月16-18日：UKB + 脑MRI影像实验

### 数据整合
- 临床特征 1,068 列 + UKB 脑 MRI IDP 2,176 列 = ~3,250 特征
- MRI 特征类型：T1结构（FreeSurfer体积/厚度/面积）、dMRI（FA/MD/ICVF等）
- 有MRI样本 ~46,000人（全队列的9.2%）
- 关键策略：无MRI者保留NaN，LightGBM原生处理缺失值

### 影像子集分析（实验2b）
仅在46,000名有MRI的参与者上独立训练s01-s04：
- 模型严重过拟合（s04训练集AUC 0.895 → s05崩溃）
- 健康志愿者偏差：有MRI者系统性更年轻健康（DM_full阳性率0.32% vs 全队列1.93%，差6倍）
- 阳性样本极少（仅148例痴呆），特征数远超阳性样本数(2,176 >> 148)

> **方法论贡献**：证明了全队列+LightGBM原生NaN处理是唯一正确的方法论。健康志愿者偏差使仅用影像子集训练不可行。

### ADNI关键发现
1. **正确目标纠正**：ADNI的CN→AD预测几乎不可行，MCI→AD才是正确预测任务(AUC 0.86)
2. **UKB和ADNI不可直接比较AUC**：UKB做人群筛查（发病率0.08-1.24%），ADNI做临床预后（转化率23-27%）
3. **Amyloid PET是最强的单一影像特征**，pTau217是最强的血浆生物标记
4. **PTWORKHS（就业状态）排名第一**：功能状态是比认知测试更客观的衰退指标
5. **小样本必须用CV校准**：split-train-calibrate在1,120人样本下崩溃(AUC 0.57)，CalibratedClassifierCV恢复到0.86

## 关键方法论贡献

1. **s04方法论修正**：论文代码是累积AUC，修正为SFS（与正文描述一致）
2. **APOE4意外排除发现**：论文s01的inner join意外排除了APOE4，论文声称含APOE4但代码未实现
3. **全队列NaN处理范式**：健康志愿者偏差使影像子集独立训练不可行，全队列+LightGBM原生NaN是最优解
4. **ADNI正确目标定义**：MCI→AD转化而非CN→AD，纠正了目标错配
5. **小样本校准修正**：CalibratedClassifierCV替代split-train-calibrate，避免1,120人→538训练样本的数据浪费
6. **跨队列不可比性证明**：UKB(筛查)和ADNI(预后)的AUC不可直接对比，事件率差300倍
