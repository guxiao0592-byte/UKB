# ADNI 外部验证实验报告

> **项目**: UKB-DRP 痴呆风险预测模型 — ADNI 独立队列外部验证
> **日期**: 2026-05-21
> **数据来源**: ADNI (Alzheimer's Disease Neuroimaging Initiative) IDA 门户
> **对比基准**: Yu et al., "Development of a novel dementia risk prediction model..." (eClinicalMedicine, 2022)

---

## 1. 实验流程

### 1.1 总体流程

本实验将论文提出的 s01-s05 LightGBM 训练管线完整应用于 ADNI 独立临床队列，验证方法学在完全不同数据源上的泛化性。核心目标是 **MCI→AD 转化预测**——即从轻度认知障碍患者中识别出将在 5 年/10 年内进展为阿尔茨海默病痴呆的人。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  Step 0: ADNI 数据下载                                                        │
│  从 IDA 门户勾选 Subjects / Assessments / Biospecimen /                       │
│  Key MRI & PET / MR & PET Image Analysis / Genetic Data                      │
│  → 66 个 CSV (人口学、认知量表、CSF/血浆生物标记、MRI、PET、APOE 基因型)        │
├──────────────────────────────────────────────────────────────────────────────┤
│  Step 1: 数据预处理 (preprocess_adni.py + build_time_targets.py)              │
│  66 个 CSV 表格 → 基线合并 (bl/sc/init 访视) → 缺失值过滤 → 特征分类           │
│  → 纵向随访诊断追踪 → 转换时间计算 → 5yr/10yr 时间窗口目标构建                  │
│  输出: ADNI_baseline_with_time_targets.csv (2,749 人 × 402 列)                │
├──────────────────────────────────────────────────────────────────────────────┤
│  Step 2: s01-s05 训练管线 (run_mci_to_ad_pipeline.py)                         │
│  筛选基线 MCI (1,120 人) → s01 特征排序 → s02 层次聚类 → s03 重排序           │
│  → s04 序列前向选择 (SFS) → s05 CalibratedClassifierCV 校准 + 5-fold 评估     │
│  目标: MCI→AD 5yr / MCI→AD 10yr / MCI→AD all-time                            │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 s01-s05 方法论

```
┌───────┬──────────────────┬──────────────────────────────────────────────────────────────┬─────────────────────────────┐
│  步骤 │ 名称             │ 方法                                                        │ 参数                        │
├───────┼──────────────────┼──────────────────────────────────────────────────────────────┼─────────────────────────────┤
│  s01  │ 特征初排序       │ LightGBM 5-fold CV，按 Gain (信息增益) 排序所有特征，取 Top 50 │ n=500, depth=15, leaves=10  │
│  s02  │ 层次聚类去冗余   │ Spearman 相关矩阵 → 距离 1-|ρ| → Ward 聚类 (阈值 0.75)       │ 距离阈值 0.75，输入 Top 50  │
│  s03  │ 聚类后重排序     │ 对聚类保留特征重新 LightGBM 5-fold CV 排序                      │ 同 s01 参数                 │
│  s04  │ 序列前向选择(SFS)│ 贪心搜索: 每步遍历剩余特征，选加入后 AUC 增益最大的                │ 最多 15 步，增益<0.0005 早停│
│  s05  │ 最终模型 + 校准   │ Top 10 特征 + LightGBM + CalibratedClassifierCV(isotonic,cv=3) │ 5-fold CV，校准后评估       │
└───────┴──────────────────┴──────────────────────────────────────────────────────────────┴─────────────────────────────┘
```

### 2.2 s04 特征选择的关键差异

论文公开代码与论文正文描述不一致。ADNI 实验采用与论文正文一致的 SFS 方法：

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│  论文公开代码 (s04_ad_clf.py) 的做法:                                                                        │
│                                                                                                            │
│    for f in s03_sorted:           ← 严格按 s03 排序，不重新选择                                              │
│        tmp_f.append(f)            ← 依次加入特征                                                             │
│        5-fold CV 训练+评估        ← 计算累积 AUC                                                            │
│    → 输出累积 AUC 曲线，研究者手工选 Top N                                                                   │
│                                                                                                            │
│  论文正文描述 & ADNI 实现 (SFS) 的做法:                                                                      │
│                                                                                                            │
│    for step in range(15):         ← 最多 15 步                                                              │
│        for cand in remaining:     ← 遍历剩余每个候选                                                         │
│            5-fold CV 训练+评估    ← 计算 AUC                                                                │
│        selected.append(best)      ← 选 AUC 最高的加入                                                        │
│        if gain < 0.0005: break    ← 增益不足时早停                                                           │
│    → 每步选全局最优，真正的序列前向选择                                                                       │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 校准方法的选择

论文内部不同阶段使用了两种不同的校准方法，未给出解释。ADNI 的选择基于样本量安全考虑：

```
┌──────────────────────────────┬──────────────────────────────────────┬──────────────────────────────────────┐
│  场景                        │ 校准方法                             │ 原因                                 │
├──────────────────────────────┼──────────────────────────────────────┼──────────────────────────────────────┤
│  论文 s05 代码               │ CalibratedClassifierCV(isotonic,cv=5)│ 包装器内置交叉校准                    │
│  论文 Deploy 脚本             │ 手动 IsotonicRegression (40%校准集)  │ 论文内部不同阶段使用不同方法，未解释   │
│  UKB 复现                    │ 手动 IsotonicRegression (40%校准集)  │ 425K 样本，切分不影响训练量            │
│  ADNI 验证                   │ CalibratedClassifierCV(isotonic,cv=3)│ 1,120 样本，手动切分导致训练崩溃       │
└──────────────────────────────┴──────────────────────────────────────┴──────────────────────────────────────┘
```

**关键经验**：split-train-calibrate (40% 校准集) 在 UKB 的 425K 样本下安全，但在 ADNI 的 1,120 MCI 样本下（5-fold CV × 40% 校准 → 每折仅 538 训练样本），性能从 AUC 0.86 崩溃至 0.57。小样本必须用 CalibratedClassifierCV 避免训练数据浪费。

### 4.4 特征差异的根本原因

```
  论文特征 (UKB) 来源结构:                     ADNI 特征 (MCI→AD) 来源结构:

  年龄 ★★★★★                                  就业状态 ★★★★★
  认知测试 ★★★★                               Amyloid PET ★★★★
  用药数量 ★★★                                MRI 结构体积 ★★★★
```

### 5.5 关键概念解释

#### (1) 评估指标含义

```
┌─────────────┬──────────────────────────────────────────────────────────────────────────────────────────────┐
│  指标       │ 含义                                                                                         │
├─────────────┼──────────────────────────────────────────────────────────────────────────────────────────────┤
│  AUC (均值) │ Area Under the ROC Curve，ROC 曲线下面积。表示模型区分"会转化"和"不会转化"的 MCI 患者的能力。  │
│             │ 0.5 = 和抛硬币一样，无预测力；0.7-0.8 = 可接受；0.8-0.9 = 良好；>0.9 = 优秀。                │
│             │ 均值是 5 折交叉验证的 5 个 AUC 的平均值。                                                     │
│  AUC (std)  │ 5 折 AUC 的标准差。表示模型在不同数据划分上的稳定性，越小越稳定。0.007 说明 5 折表现高度一致。 │
│  Brier      │ Brier Score，预测概率的均方误差 = (1/n) Σ(predᵢ - trueᵢ)²。越小越好。0 = 完美，              │
│             │ 0.25 = 对 50% 患病率的数据毫无信息。0.126 意味着预测概率和实际结果之间的偏差较小。              │
│  Sens       │ Sensitivity (敏感性/召回率)：真正会转化的 MCI 患者中，被模型正确识别为"高风险"的比例。       │
│             │ 0.876 = 87.6% 的转化者被正确预警。                                                            │
│  Spec       │ Specificity (特异性)：真正不会转化的 MCI 患者中，被模型正确识别为"低风险"的比例。             │
│             │ 0.703 = 70.3% 的非转化者被正确排除。                                                          │
│  at-risk    │ 进入分析的基线 MCI 患者总数。这些人都有认知障碍但目前尚未痴呆。                               │
│  事件数     │ at-risk 人群中在目标时间窗口内实际转化为 AD 的人数。258/1,120 = 23.0% 的转化率。              │
│  转化率     │ 事件数 ÷ at-risk。ADNI 的 MCI→AD 5yr 转化率 (23%) 远高于 UKB 的 AD_5yrs 发病率 (0.08%)，      │
│             │ 因为 ADNI 的 MCI 患者已经处于疾病进展轨道上。                                                  │
└─────────────┴──────────────────────────────────────────────────────────────────────────────────────────────┘
```

**敏感性 vs 特异性的权衡**

敏感性和特异性是一对此消彼长的指标。模型输出的不是"会/不会"的标签，而是一个 0-1 之间的风险概率。我们需要选一个截断点 (cutoff)：概率 ≥ 截断点的判为"高风险"，< 截断点的判为"低风险"。截断点越低，敏感性越高（更多人被预警）但特异性越低（更多健康人被误报）。本实验使用 Youden 指数 (Sens + Spec − 1) 最大的点作为最优截断点。

#### (2) 特征消融实验在做什么

特征消融实验回答的问题是：**"不同类型的特征各自贡献了多少预测能力？"**

```
  实验设计:
  
    Model A:  仅人口学 + 血浆生物标记 (20 个特征)      → AUC 0.818
    Model B:  人口学 + 血浆生物标记 + 全部影像 (358 特征) → AUC 0.860
                                                          Δ = +0.042
  
  如果 Δ 很大 → 影像特征是独立且重要的预测信号
  如果 Δ 很小 → 影像信息已经被生物标记覆盖了 (冗余)
```

实验结果表明影像特征贡献了 +0.042 的 AUC 增量，这意味着：
- 生物标记 (pTau217、NfL、GFAP、APOE4 等) 已经包含了大部分预测信息
- 但 MRI 结构 + Amyloid/Tau PET 仍能提供独立的结构确证，额外提升约 4% 的区分能力
- 这 4% 在临床决策中的价值取决于具体场景：如果是低成本筛查，可能不值得为 4% 的增益做 PET 扫描；但在记忆诊所中，这 4% 可能就是决定"现在开始治疗"还是"继续观察"的关键

#### (3) 为什么 SFS 逐步增益的 AUC (0.872) 高于最终 s05 AUC (0.860)

SFS 逐步累积的 AUC (0.872) 比 s05 的最终 AUC (0.860) 高了约 0.012，原因如下：

```
  ┌──────────────────────────────────────────────────────────────────────────────────┐
  │  s04 步骤内评估 (AUC 0.872):                                                      │
  │                                                                                  │
  │    5-fold CV 直接训练 LightGBM → 输出原始预测概率 → 计算 AUC                       │
  │    模型可以自由地输出任何概率值，不受校准约束                                        │
  │    → 这个 AUC 衡量的是模型的 "排序能力" (ranking)，偏向乐观                           │
  │                                                                                  │
  │  s05 最终评估 (AUC 0.860):                                                         │
  │                                                                                  │
  │    5-fold CV 训练 LightGBM → 用 CalibratedClassifierCV 校准 → 计算 AUC             │
  │    校准过程将概率"拉回"真实频率，可能轻微改变样本间的概率排序                          │
  │    → 这个 AUC 衡量的是模型在真实场景中的表现，更接近实际部署效果                        │
  │                                                                                  │
  │  差距 0.012 是预期范围内的，说明模型没有严重过拟合                                     │
  │  如果差距 > 0.05，说明 s04 选择的特征在严格评估下失效，需要重新审视特征选择              │
  └──────────────────────────────────────────────────────────────────────────────────┘
```

更技术性地讲，s04 的 SFS 使用 `LGBMClassifier.fit().predict_proba()` 直接输出概率计算 AUC，而 s05 通过 `CalibratedClassifierCV` 在内部再做了 3 折交叉校准。校准后的概率分布更接近真实发病率，可能导致 AUC 的微小变化（通常略降）。这个差距是正常的，且在 0.012 的水平上说明模型泛化能力良好。

#### (4) 五折交叉验证和 CalibratedClassifierCV 的区别

这是两个完全不同的概念，作用于不同的环节：

```
  ┌──────────────────────────────────────────────────────────────────────────────────────┐
  │                                                                                      │
  │  5-Fold Cross-Validation (五折交叉验证)                                                │
  │  ─────────────────────────────────────                                                │
  │  作用: 评估模型的泛化性能                                                               │
  │  做法: 把全部数据分成 5 份                                                              │
  │         ┌──────┬──────┬──────┬──────┬──────┐                                          │
  │         │ Fold1│ Fold2│ Fold3│ Fold4│ Fold5│                                          │
  │         └──────┴──────┴──────┴──────┴──────┘                                          │
  │         4 份训练 → 1 份测试，轮流 5 次                                                   │
  │         报告 5 次 AUC 的均值 ± 标准差                                                    │
  │                                                                                      │
  │  CalibratedClassifierCV (交叉校准分类器)                                                │
  │  ─────────────────────────────────────────                                            │
  │  作用: 让模型输出的概率变得准确 (校准)                                                    │
  │  做法: 包装一个分类器，内部再做交叉验证                                                   │
  │         训练数据: ┌──────┬──────┬──────┐                                               │
  │                  │ cv=3 │ cv=3 │ cv=3 │  ← 内层 3 折                                   │
  │                  └──────┴──────┴──────┘                                               │
  │         在训练集上做 3 折 CV → 得到校准后的概率 → 用 Isotonic Regression 调整            │
  │                                                                                      │
  │  两者的关系:                                                                           │
  │                                                                                      │
  │    外层 5-fold CV (评估模型好不好)                                                      │
  │        │                                                                              │
  │        └── 每折内部: CalibratedClassifierCV (让概率准确)                                 │
  │               └── 内层 3-fold CV (校准用)                                               │
  │                                                                                      │
  │    外层 5 折保证评估无偏 → "这个模型的 AUC 是 0.86"                                       │
  │    内层 3 折保证概率准确 → "这个模型说 30% 风险的人，真的有 ~30% 转化了"                     │
  │                                                                                      │
  └──────────────────────────────────────────────────────────────────────────────────────┘
```

**简单类比**：五折交叉验证是"考试"（考 5 次看平均分），CalibratedClassifierCV 是"考前校准"（确保你打的分数和真实水平对应，不会一直高估或低估自己）。两者解决不同的问题。

#### (5) 为什么小样本必须用 CV 校准 —— 以及 split-train-calibrate 的失败

UKB 复现使用的校准方式是将训练集切分为 60% 真正训练 + 40% 校准集（split-train-calibrate）。这在 UKB 的 425K 样本下完全可行。但在 ADNI 中，同样的方法导致了灾难性失败：

```
  小样本下 split-train-calibrate 的崩溃过程:
  
    ADNI MCI 队列: 1,120 人
    外层 5-fold CV:   每折测试集 = 224 人, 训练集 = 896 人
    训练集切分:       40% 校准集 = 358 人, 真正训练 = 538 人
  
    538 个训练样本  ×  358 个特征  →  严重的数据不足
    → 特征数接近样本数 → LightGBM 过拟合
    → 在 358 人的小校准集上做 Isotonic Regression → 校准不稳定
    → AUC 从 0.86 崩溃到 0.57
  
  CalibratedClassifierCV 如何解决:
  
    不切分训练集 — 全部 896 个样本参与训练
    内部 3 折 CV: 每次 597 人训练 → 299 人预测概率 → 汇总后拟合 Isotonic Regression
    → 每个样本都参与训练，也都有校准后的概率输出
    → AUC = 0.860
```

```
┌──────────────────────────────────┬──────────────────────────────┬──────────────────────────────┐
│  方法                            │ 原理                         │ 适用条件                      │
├──────────────────────────────────┼──────────────────────────────┼──────────────────────────────┤
│  split-train-calibrate (40/60)   │ 训练集切一块出来专做校准      │ 大样本 (>10K)，切分不影响训练  │
│  CalibratedClassifierCV (cv=3)   │ 全部数据训练，内部 3 折出概率  │ 小样本 (<5K)，不能浪费任何数据  │
└──────────────────────────────────┴──────────────────────────────┴──────────────────────────────┘
```

**规则**：当 `(训练集大小 × 60%) < (特征数 × 10)` 时，split-train-calibrate 不再安全，必须改用 CalibratedClassifierCV。ADNI 中 `538 < 3580` (358 × 10)，触发此条件。

#### (6) 校准究竟在做什么，为什么必须做

**校准问题本身**：一个未校准的模型可能输出"这个人有 80% 的概率转化为 AD"，但实际上在这类预测为 80% 的人中只有 50% 真正转化了。这意味着模型系统性地高估了风险。

```
  直观例子:
  
    未校准模型:                   校准后模型:
    
    预测概率  实际转化率           预测概率  实际转化率
    0.1  →    5%                  0.1  →    10%
    0.3  →    15%                 0.3  →    28%
    0.5  →    25%                 0.5  →    51%   ← 校准后接近 45° 线
    0.7  →    40%                 0.7  →    72%
    0.9  →    55%                 0.9  →    88%
    
    模型说 90% → 实际只有 55%        模型说 90% → 实际 88%
    ↑ 严重高估，不能用于临床           ↑ 基本准确，可以告诉患者
```

**Isotonic Regression (保序回归) 如何校准**：

```
  Step 1: 收集训练集中所有样本的原始预测概率和真实标签
  Step 2: 把概率从小到大排序，分段计算每段的实际转化率
  Step 3: 拟合一个单调非降的映射函数 f(x) → y，其中 x=原始概率, y=实际转化率
  Step 4: 对新样本: 原始概率 → 经过 f() 映射 → 校准后的概率
```

**为什么必须做**：

1. **临床决策需要准确的风险数字**：告诉患者"你有 60% 的概率在 5 年内进展为 AD 痴呆"和"你属于高风险组"是两种完全不同的沟通方式。前者需要校准，后者只需要排序。
2. **LightGBM 天然倾向于输出极端概率**：树的集成模型容易在叶节点中出现极度不平衡的样本，导致输出概率偏向 0 或 1。
3. **MCI 患者做治疗决策时，风险概率的准确性直接影响临床行动**：如果模型高估风险，会导致过度治疗和患者焦虑；如果低估，会延误干预窗口。

**论文和 ADNI 实验都使用 Isotonic Regression 进行校准，这是该领域的事实标准方法**——它不对概率分布做任何假设（区别于 Platt Scaling 假设 sigmoid），适合医学预测场景。

## 6. 结果解读

### 6.1 MCI→AD 5yr AUC 0.86 的含义

1. **该结果在临床上有实际价值**

   MCI 是痴呆诊疗路径上的关键决策点。MCI 患者和家属的核心问题是"病情会如何进展"。AUC 0.86 意味着可以在 MCI 群体中较好地区分 5 年内会转为 AD 的患者和不会转的患者。

2. **血浆 + 影像是最有效的组合策略**

   - 仅靠人口学和血浆生物标记 (pTau217, NfL, GFAP, APOE4) 已达 AUC 0.818
   - 加入 Amyloid PET (+0.012)、Tau PET (+0.003)、MRI 结构 (+0.046) 后增至 0.860
   - 影像的总增量 (+0.042) 不大但稳健，尤其在最具临床意义的 5 年窗口上

3. **PTWORKHS (就业状态) 排第一的临床含义**

   功能状态（是否还能继续工作）是比认知测试更客观的衰退指标。就业状态的变化不像认知测试分数那样容易受测试条件影响，可能反映了更真实的功能储备和认知储备。

4. **Amyloid PET 是最强的单一影像预测因子**

   淀粉样蛋白沉积是 AD 的必要条件。A+ MCI 几乎注定会转化为 AD，而 A- MCI 的转化率极低。这验证了 ATN 生物标记框架中 A (Amyloid) 维度在 MCI 预后中的核心地位。

### 6.2 为什么 ADNI 不适合做人群筛查

```
┌─────────────────────────────┬──────────────────────────────────────────────────────────────────┐
│  原因                       │ 说明                                                             │
├─────────────────────────────┼──────────────────────────────────────────────────────────────────┤
│  队列偏差                   │ ADNI 的 CN (认知正常者) 都是"有记忆担忧才来就诊"的人，不代表社区普通 CN│
│  年龄范围窄                 │ 55-90 岁，不能外推到 40-55 岁的社区筛查场景                         │
│  特征不可得                 │ Amyloid PET (数万元)、Tau PET、CSF 穿刺在社区筛查中完全不可用        │
│  样本量小                   │ 1,120 人 MCI，远小于 UKB 的 425K，不适合开发面向百万人的筛查工具      │
└─────────────────────────────┴──────────────────────────────────────────────────────────────────┘
```

### 6.3 为什么 UKB 不适合做临床预后

```
┌─────────────────────────────┬──────────────────────────────────────────────────────────────────┐
│  原因                       │ 说明                                                             │
├─────────────────────────────┼──────────────────────────────────────────────────────────────────┤
│  无 MCI 诊断                │ UKB 没有轻度认知障碍的临床诊断分类                                  │
│  无 AD 病理标记             │ 没有 Amyloid PET、Tau PET、CSF Aβ/pTau                             │
│  诊断延迟                   │ AD 诊断来自 HES 电子健康记录，通常比实际发病晚数年                   │
│  漏诊率高                   │ 社区中大量早期 AD 未被诊断，#实际患病人数远多于 #记录病例数           │
└─────────────────────────────┴──────────────────────────────────────────────────────────────────┘
```

### 6.4 两个队列的互补定位

```
┌─────────────────────────────────────────────────────────────────────────────────────────────┐
│                                                                                             │
│   临床阶段:     健康人群  ────→  认知担忧  ────→  轻度认知障碍  ────→  阿尔茨海默病痴呆       │
│                       │                │              │                                       │
│   适用模型:      UKB 筛查模型         │         ADNI 预后模型                                  │
│   回答的问题:    "谁该去检查？"        │        "病情会多快恶化？"                               │
│   所需数据:      问卷+体检+血检         │        PET+CSF+血浆+MRI                                │
│   部署场景:      社区/基层医疗           │        记忆诊所/神经内科                                │
│   单次成本:      低 (＜100 元/人)        │        高 (＞1 万元/人)                                 │
│                                                                                             │
│   → UKB 和 ADNI 不是竞争关系，而是覆盖临床路径的不同阶段。两者不可互相替代。                      │
│   → 两者的 AUC 数值不应该被放在同一张表里直接比较。                                             │
│                                                                                             │
└─────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 6.5 核心结论

```
┌──────┬────────────────────────────────────────────────┬──────────────────────────────────────────────────┐
│  编号 │ 结论                                           │ 证据                                             │
├──────┼────────────────────────────────────────────────┼──────────────────────────────────────────────────┤
│   1   │ s01-s05 pipeline 在独立临床队列上可泛化        │ MCI→AD 5yr AUC 0.86，方法学完整复现，性能稳健     │
│   2   │ ADNI 的正确预测任务不是 CN→AD，而是 MCI→AD     │ CN→AD 5yr AUC 0.71 vs MCI→AD 5yr AUC 0.86       │
│   3   │ Amyloid PET + pTau217 + MRI 是 MCI 预后核心   │ 消融实验: Bio (0.818) → +Imaging (0.860)          │
│   4   │ 小样本必须用 CalibratedClassifierCV            │ split-train-calibrate 崩溃至 0.57                 │
│   5   │ UKB(筛查) 和 ADNI(预后) 不应直接比较 AUC       │ 事件率差 300 倍，预测对象完全不同                   │
│   6   │ 功能状态 (PTWORKHS) 是比认知测试更客观的指标    │ 在 MCI→AD 5yr SFS 中排第 1 位                     │
└──────┴────────────────────────────────────────────────┴──────────────────────────────────────────────────┘
```
