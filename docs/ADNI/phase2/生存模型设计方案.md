# MCI→Dementia 生存预测 — 标签设计与模型方案

> 日期: 2026-06-11 | 阶段: Phase 2B

---

## 1. 为什么从二分类转向生存标签

### 1.1 二分类的问题

```
当前 (Phase 2A): 3个独立二分类模型
  ├── MCI→Dementia 3yr:  P(T≤3|X) — 600人训练, 排除520删失
  ├── MCI→Dementia 5yr:  P(T≤5|X) — 500人训练, 排除620删失
  └── MCI→Dementia 10yr: P(T≤10|X) — 385人训练, 排除735删失

问题:
  1. 删失浪费: 3yr丢了46%的MCI, 5yr丢了55%, 这些人的信息被丢弃
  2. 时间坍缩: 1.5年转化和3.0年转化在3yr模型中都是y=1, 转化速度差异丢失
  3. 不一致风险: 三个独立模型可能输出 P(≤1yr)>P(≤3yr)
  4. 回答不了"什么时候转": 只能回答固定窗口的"转不转"
```

### 1.2 生存标签的优势

```
Phase 2B: 1个生存模型
  ├── 训练集: 944人 (排除176个零随访)
  ├── 事件: 323人转化, 621人删失
  ├── 输出: 个体生存曲线 S(t|X)
  └── 从中读出: risk_1y, risk_3y, risk_5y

优势:
  1. 保留全部可用样本: 删失者贡献 P(T>t|censored) 的信息
  2. 连续时间建模: 精确到年, 不坍缩
  3. 天然一致: S(1)≥S(3)≥S(5), 自动保证 risk_1y≤risk_3y≤risk_5y
  4. 一个模型回答所有窗口
```

## 2. 生存标签设计

### 2.1 构建规则

从现有 v2 数据直接提取, 无需重新跑 `build_time_targets_v2.py`:

```python
# 终点: MCI→Dementia (Broad)
# converted_to_dementia = 1 当出现 DIAGNOSIS=3 OR DXPARK=1 OR DXOTHDEM=1

surv_time = np.where(
    converted_to_dementia == 1,
    dementia_conversion_years,   # 事件: 基线→首次痴呆诊断
    last_followup_years           # 删失: 基线→最后有效随访
)
surv_event = converted_to_dementia  # 1 = 痴呆, 0 = 未观察到痴呆
```

### 2.2 排除规则

排除 `surv_time == 0` 的受试者（176人: 仅有基线DXSUM, 无纵向信息）。

### 2.3 最终标签

```
┌──────────┬──────────────────────────────────────────────────────────────┐
│ 944 MCI  │                                                              │
├──────────┼──────────────────────────────────────────────────────────────┤
│ 事件     │ 323 人 (34.2%) — 确切转化时间                                │
│          │   中位: 2.03年, 均值: 3.1年                                  │
│          │   [0.04-1]yr: 46, [1-3]yr: 150, [3-5]yr: 71, [5-20]yr: 56  │
├──────────┼──────────────────────────────────────────────────────────────┤
│ 删失     │ 621 人 (65.8%) — 最少已知未转化时间                            │
│          │   中位: 1.83年, 均值: 3.0年                                  │
│          │   <1yr: 166, [1-3]yr: 182, [3-5]yr: 100, [5-20]yr: 173     │
└──────────┴──────────────────────────────────────────────────────────────┘
```

### 2.4 与二分类标签的关系

```
同一批 MCI 患者, 两种标签视角:

RID=41:  MCI→AD @1.5yr  →  surv (1.5, 1)      二分类: 3yr=1, 5yr=1
RID=126: MCI→AD @3.0yr  →  surv (3.0, 1)      二分类: 3yr=0, 5yr=1  ← 标签翻转
RID=1108: MCI→MCI @6.5yr →  surv (6.5, 0)      二分类: 3yr=0, 5yr=0, 10yr=censored
RID=4249: MCI→MCI @3.0yr →  surv (3.0, 0)      二分类: 3yr=0, 5yr=censored

生存标签不需要区分 "3yr阴性" 还是 "5yr删失" — 它只记录 (3.0, 0), 
模型自己学会: "如果这个人活到3年, 他再活到5年的概率是 S(5)/S(3)"
```

### 2.5 区间删失说明

真实转化时间在最后MCI访视和首次痴呆诊断之间。本方案采用右端点法（首次痴呆诊断日期 = 转化时间）。可在后续做中点法敏感性分析。

## 3. 模型架构 (保持 s01-s05 管线)

### 3.1 不改变的核心

- s01-s05 管线结构 (排序→聚类→重排→SFS→评估)
- 5-fold CV
- 358 特征 (Bio+Img, 排除认知测试+CDR)
- CalibratedClassifierCV 校准
- 特征排除策略不变

### 3.2 仅改变的

| 组件 | 二分类 (Phase 2A) | 生存 (Phase 2B) |
|------|-------------------|-----------------|
| 标签 y | `Dementia_3yrs ∈ {0,1}` | `(surv_time, surv_event)` |
| 训练集 | 按窗口各自筛选 | 统一 944 人 |
| s01 排序指标 | Gain (分类) | C-index (生存) |
| s04 SFS 指标 | AUC | C-index |
| s05 模型 | `LGBMClassifier` | `LGBMRegressor(objective='cox')` |
| s05 评估 | AUC, Sens, Spec, Brier | C-index, tAUC@1/3/5yr, Brier@1/3/5yr |
| 输出 | P(转化∈window) | S(t\|X), risk_1y, risk_3y, risk_5y |

### 3.3 完整的 s01-s05 生存版

```
s01: LightGBM Cox 5-fold CV → C-index 排序 → Top 50
     替代: LGBMClassifier(gain) → LGBMRegressor(objective='cox', feature_importance)

s02: Ward 聚类去冗余 (Spearman |ρ|, 阈值 0.75)
     → 与二分类相同, 特征间相关性计算不变

s03: 聚类后 Cox 重排序 → Top N
     替代: AUC → C-index

s04: Sequential Forward Selection
     替代: 每步评估 AUC → 每步评估 C-index
     早停: C-index增益 < 0.0005

s05: 最终模型 (3个):
     ├── GB-Cox: LGBMRegressor(objective='cox') ★主模型
     ├── Cox PH: lifelines.CoxPHFitter (可解释性基准)
     └── (可选) RSF: RandomSurvivalForest

     评估 (5-fold CV):
     ├── C-index (Harrell's)
     ├── tAUC @ 1yr, 3yr, 5yr
     ├── Brier Score @ 1yr, 3yr, 5yr
     └── Integrated Brier Score (0-5yr)
```


## 7. 与二分类的关键差异总结

| | 二分类 (已完成) | 生存 (本方案) |
|---|---|---|
| **标签** | `y_3yr`, `y_5yr`, `y_10yr` (0/1) | `(time, event)` 一对 |
| **样本** | 按窗口切分: 600/500/385人 | 统一: 944人 |
| **删失者** | 丢弃 | 保留为 `(t, 0)` |
| **模型数** | 3-4个独立模型 | 1个模型 |
| **s01-s04** | LGBMClassifier + AUC | LGBMRegressor(cox) + C-index |
| **s05** | CalibratedClassifierCV | Cox PH / GB-Cox |
| **输出** | 固定窗口概率 | 完整生存曲线 + 任意时间点风险 |
| **一致性** | 不保证 | 自动保证 S(1)≥S(3)≥S(5) |
