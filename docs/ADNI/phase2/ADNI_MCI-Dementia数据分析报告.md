# ADNI MCI→痴呆 预测 — 数据分析报告

> 日期: 2026-06-10
> 数据源: ADNI DXSUM (16,118 visits, 3,685 subjects)
> 预处理基线: 2,749 subjects, MCI = 1,120
> 版本: v2.0 (含删失标记的修正版目标变量)

---

## 1. 终点定义

### 1.1 两种 Dementia 定义对比

```
┌──────────────────────────────────────────────────────────────────┐
│ 终点定义                    总事件     占比                      │
├──────────────────────────────────────────────────────────────────┤
│ Narrow: AD痴呆 (DIAG=3)       307    27.4%                      │
│ Broad:  任意痴呆              323    28.8%                      │
│   ├─ AD dementia              307    (95.0% of broad)           │
│   ├─ Parkinson's dementia      14                               │
│   └─ Other dementia             2                               │
└──────────────────────────────────────────────────────────────────┘
```

**结论**: AD 痴呆占 MCI 转化的 95%。Broad 定义仅多捕获 16 例，但临床意义更完整（覆盖非 AD 痴呆路径）。**推荐使用 Broad 定义 (Dementia)**。

### 1.2 痴呆转化判定规则

`converted_to_dementia = 1` 当且仅当基线 MCI (DIAGNOSIS=2) 患者在随访中出现：
- DIAGNOSIS = 3 (AD dementia)，或
- DXPARK = 1 (Parkinson's disease dementia)，或
- DXOTHDEM = 1 (Other dementia)

### 2.3 删失原因分析

**310 人 (27.7%) 仅有基线 DXSUM 记录**，在任何时间窗口内都不是有效样本。这是删失的主要来源。

3年窗口删失 (520人) 的构成：
- **60% 仅有基线访视** (310人, f/u=0yr) — ADNI4 近期入组 + 一次评估即脱落
- **22% f/u 1-2年** (114人) — 有1-2次随访但<3年
- **12% f/u 2-3年** (64人) — 接近但不足3年
- 6% f/u 0.5-1年 (32人)

按研究阶段分布 (3年删失)：
- ADNI4: 216人 (最新入组，随访时间自然短)
- ADNI3: 181人
- ADNI1: 95人
- ADNIGO: 28人

## 4. 转化者 vs 非转化者 基线特征对比

### 4.1 5年窗口内

```
┌──────────────────────┬──────────────┬──────────────┬──────────────┐
│ 特征                 │ 5yr内转化    │ 5yr未转化    │ p-value      │
│                      │ (n=267)      │ (n=177)      │ (Mann-Whitney)│
├──────────────────────┼──────────────┼──────────────┼──────────────┤
│ 年龄 (中位)          │   75 岁      │   71 岁      │  <0.0001     │
│ APOE4 携带率         │   62%        │   32%         │  —           │
│ MMSE (中位)          │   27         │   29          │  <0.0001     │
│ CDR-SB (中位)        │   2.0        │   1.0         │  <0.0001     │
│ FAQ (中位)           │   4          │   0           │  —           │
│ ADAS-Total (中位)    │   13         │   7           │  —           │
└──────────────────────┴──────────────┴──────────────┴──────────────┘
```

**解读**: 转化者显著年龄更大 (+4岁)、APOE4 携带率翻倍 (62% vs 32%)、基线认知功能更差 (MMSE -2分, CDR-SB +1分)。这是预期结果——MCI 严重度本身就是最强的预后信号。

### 4.2 删失样本特征

删失者 (f/u<5yr且未转化, n=620) 的基线特征与真阴性相似 (年龄73岁, APOE4+ 33%, MMSE 28, CDR-SB 1.0)，提示删失更可能是**数据收集机制**导致（ADNI4新入组、脱落），而非疾病严重度驱动。

## 6. 实验可行性评估

### 6.1 三窗口对比

```
┌──────┬──────────┬──────────┬──────────┬──────────────────────────────┐
│ 窗口 │ 有效样本 │ 事件数   │ 事件:阴性│ 评估                         │
├──────┼──────────┼──────────┼──────────┼──────────────────────────────┤
│ 3年  │   600    │   196    │  1:2.1   │ ★★★ 最优 — 样本大,删失少     │
│ 5年  │   500    │   267    │  1:0.9   │ ★★★ 核心 — 临床标准窗口      │
│ 10年 │   385    │   311    │  1:0.24  │ ★★  辅助 — 阴性极少,易过拟合  │
└──────┴──────────┴──────────┴──────────┴──────────────────────────────┘
```

### 6.2 推荐实验方案

**主实验: MCI→Dementia 3yr**
- 有效样本 600 人，删失率最低 (46%)
- 可用的阳性样本合理 (196 events, 32.7%)
- 阴性样本充足 (404), 类别相对平衡 (1:2.1)
- 中位转化 2.0 年 → 3年窗口合理覆盖

**对比实验: MCI→Dementia 5yr**
- 有效样本 500 人，转化率 53.4%
- 临床最常用的预后窗口
- 与之前未排除删失的 AUC 0.86 对比差异

**辅助实验: MCI→Dementia 10yr**
- 仅 385 有效样本，真阴性仅 74 人
- 类别极度不平衡 (1:0.24)，可作探索

### 6.3 不可行的实验

| 实验 | 原因 |
|------|------|
| CN→Dementia 3yr | **0 个事件** (CN→MCI→AD至少需4-5年) |
| CN→Dementia 5yr | 4 个事件，不具统计效力 |
| CN→AD any window | 3yr仅1例, 5yr仅4例, 10yr仅23例 |

## 7. 与之前实验的关键差异

### 7.1 之前实验的问题

原始 `build_time_targets.py` 存在 bug：`last_followup_years` 未正确合并到输出，导致删失标记失效。此前 MCI→AD 5yr 实验对 **全部 1,120 人** 建模，含 627 例 f/u<5yr 的非转化者被错误标记为阴性。

