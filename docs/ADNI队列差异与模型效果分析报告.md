# ADNI vs UKB 队列差异与模型效果深度分析

> 回答三个核心问题：(1) CN→AD 是什么；(2) 数据集和队列差异如何影响模型效果；(3) 解决方案。

---

## 1. CN→AD 是什么

### 1.1 定义

```
CN (Cognitively Normal)  →  MCI (Mild Cognitive Impairment)  →  AD (Alzheimer's Disease)
认知正常                     轻度认知障碍                          阿尔茨海默病痴呆
```

**CN→AD** 指一个人在基线时认知正常，但在随访期间被诊断为阿尔茨海默病痴呆。

### 1.2 两种转换路径

┌──────────────────────┬──────────────────────────────┬─────────────┬────────────────────────────┐
│ 路径                 │ 描述                         │ ADNI 中数量 │ 中位时间                   │
├──────────────────────┼──────────────────────────────┼─────────────┼────────────────────────────┤
│ **CN→AD (直接)**     │ 从认知正常直接进展到 AD 痴呆 │ 9 人        │ 8.1 年                     │
│ **CN→MCI→AD (间接)** │ 先转为 MCI，再转为 AD        │ 38 人       │ CN→MCI 4.1年, MCI→AD 2.9年 │
│ **MCI→AD**           │ 基线已是 MCI，随访中转为 AD  │ 414 人      │ 2.1 年                     │
└──────────────────────┴──────────────────────────────┴─────────────┴────────────────────────────┘

**关键事实**：绝大多数 CN→AD 都经过 MCI 阶段。直接从 CN 跳到 AD 极为罕见（仅 9 例）。这意味着：

- 在 5 年内，CN 受试者最多只能进展到 MCI 阶段
- 要预测 "CN 在 5 年内是否变 AD"，答案几乎是 "不可能"，因为病理需要更长时间

### 1.3 为什么这很重要

论文中的 AD_5yrs 目标和 ADNI 中的 AD_5yrs 目标**测量的是完全不同的东西**：

┌─────────────┬────────────────────────────┬────────────────────────────────────────┐
│ 维度        │ UKB AD_5yrs                │ ADNI AD_5yrs                           │
├─────────────┼────────────────────────────┼────────────────────────────────────────┤
│ 基线状态    │ 健康人群（未诊断任何痴呆） │ CN 或 MCI（记忆诊所就诊者）            │
│ 5年内发病者 │ 临床前阶段的隐匿患者       │ **主要是 MCI→AD**（352/2,379 = 14.8%） │
│ 预测任务    │ 从人群中早期筛出高危者     │ 从已有认知下降者中预测近期恶化         │
│ 本质        │ **筛查任务**               │ **预后任务**                           │
└─────────────┴────────────────────────────┴────────────────────────────────────────┘

## 2. 数据集和队列差异如何影响模型效果

### 2.1 核心差异全景

┌───────────────┬──────────────────────────────┬───────────────────────────────────────┬─────────────────────────────────────────────────┐
│ 维度          │ UK Biobank                   │ ADNI                                  │ 对模型的影响                                    │
├───────────────┼──────────────────────────────┼───────────────────────────────────────┼─────────────────────────────────────────────────┤
│ **队列类型**  │ 人群队列                     │ 临床队列                              │ UKB 模型适合人群筛查，ADNI 模型适合临床预后     │
│ **样本量**    │ 425,159                      │ 2,749                                 │ UKB 有充足统计效力，ADNI 易过拟合               │
│ **年龄**      │ 40-69岁（中位 58）           │ 55-90岁（中位 ~75）                   │ 年龄在 UKB 中变异大，预测力强；在 ADNI 中变异小 │
│ **AD 患病率** │ 0.57%（全时段）              │ 22.9%（AD vs CN 横断面）              │ ADNI 的类别更 "干净" 但更不平衡                 │
│ **诊断方式**  │ HES/GP 电子健康记录          │ 专家临床共识诊断                      │ ADNI 诊断更准确（金标准），UKB 诊断可能有漏诊   │
│ **生物标记**  │ 基础血液检测                 │ CSF Aβ/pTau, 血浆 pTau217, NfL, GFAP  │ ADNI 有直接测量 AD 病理的能力                   │
│ **脑影像**    │ UKB IDP（自动处理，902特征） │ FreeSurfer v7 + Amyloid PET + Tau PET │ ADNI 有淀粉样蛋白和 Tau 沉积的直接测量          │
│ **随访方式**  │ 被动（HES 链接）             │ 主动（定期访视 6/12/24月）            │ ADNI 可更早捕获认知变化                         │
│ **认知评估**  │ 简单计算机测试               │ 全套神经心理电池                      │ ADNI 认知数据更丰富但也更易泄漏                 │
│ **遗传**      │ APOE4（部分缺失）            │ APOE 基因型（完整）                   │ ADNI 有 E2/E3/E4 完整分型                       │
└───────────────┴──────────────────────────────┴───────────────────────────────────────┴─────────────────────────────────────────────────┘

### 2.2 为什么不能直接比较 AUC 数值

两个队列即使使用相同名称的目标（如 AD_5yrs），预测的也不是同一件事：

┌──────────┬────────────────────────────────────────────┬────────────────────────────────────────────┬──────────────────┐
│ 同一名称 │ UKB 中的含义                               │ ADNI 中的含义                              │ 本质差异         │
├──────────┼────────────────────────────────────────────┼────────────────────────────────────────────┼──────────────────┤
│ AD_5yrs  │ 从 425K 健康人中找到 329 例 (0.08%) 5yr AD │ 从 1,120 MCI 中找到 258 例 (23%) 5yr 转 AD │ **筛查 vs 预后** │
│ AD_full  │ 不限时间的全人群 AD 发病                   │ 不限时间的 MCI→AD 转化                     │ 事件率差 50 倍   │
└──────────┴────────────────────────────────────────────┴────────────────────────────────────────────┴──────────────────┘

**结论：UKB 和 ADNI 的 AUC 不能放在同一张表里对比。** 这就像比较 "在机场找到恐怖分子" 和 "在 ICU 预测死亡风险" 的 AUC——任务难度完全不同。

### 2.3 ADNI 的正确预测任务：MCI→AD 转化

ADNI 的队列设计（记忆诊所患者、有 CSF/PET、定期随访）决定了它的核心临床问题是 **"MCI 患者何时进展为 AD"**，而不是 "谁最终会得 AD"。

**MCI→AD 预测结果**（1,120 名基线 MCI 患者，Biomarkers+Imaging 干净模型）：

┌─────────────────┬───────────────────┬───────┬───────┬───────┬───────────────────┐
│ 目标            │ AUC ± std         │ Brier │ Sens  │ Spec  │ 事件数 (占比)     │
├─────────────────┼───────────────────┼───────┼───────┼───────┼───────────────────┤
│ **MCI→AD 5yr**  │ **0.860 ± 0.007** │ 0.126 │ 0.876 │ 0.702 │ 258/1,120 (23.0%) │
│ MCI→AD 10yr     │ 0.836 ± 0.031     │ 0.141 │ 0.835 │ 0.734 │ 297/1,120 (26.5%) │
│ MCI→AD all-time │ 0.844 ± 0.032     │ 0.142 │ 0.844 │ 0.701 │ 307/1,120 (27.4%) │
└─────────────────┴───────────────────┴───────┴───────┴───────┴───────────────────┘

**特征消融** (MCI→AD 5yr)：

┌─────────────────────────────────────────┬───────────┬───────┬────────────┐
│ 特征集                                  │ AUC       │ Brier │ Δ          │
├─────────────────────────────────────────┼───────────┼───────┼────────────┤
│ Demographics + Biomarkers only (20特征) │ 0.818     │ 0.140 │ baseline   │
│ **Biomarkers + Imaging** (358特征)      │ **0.860** │ 0.126 │ **+0.042** │
└─────────────────────────────────────────┴───────────┴───────┴────────────┘

**Top 5 预测因子**：PTWORKHS（功能状态）> Amyloid PET SUVR > MRI 结构体积 > NfL（轴突损伤）> APOE4

### 2.4 为什么 MCI→AD 的 5yr AUC (0.860) 是合理的

1. **MCI 是 AD 临床路径上的核心决策点**——患者和医生在此处面临治疗/护理决策
2. **5 年窗口匹配临床需求**——MCI 转 AD 中位 2.1 年，5 年覆盖 85% 的转化者
3. **Amyloid PET 的作用**——淀粉样蛋白阳性是 AD 的必要条件，A+ MCI 几乎都会转化
4. **PTWORKHS 排第一的含义**——功能状态（能否继续工作）是比认知测试更客观的衰退指标
5. **影像增量适中 (+0.042)**——生物标记已经很强，影像提供结构确证

### 3.3 跨队列整合方向

┌────────────────┬──────────────────────────────────────────────────┬──────────────────────────────────┐
│ 策略           │ 内容                                             │ 预期收益                         │
├────────────────┼──────────────────────────────────────────────────┼──────────────────────────────────┤
│ **队列合并**   │ 将 UKB 和 ADNI 的可对齐特征合并训练              │ 让模型同时学习人群规律和临床规律 │
│ **迁移学习**   │ UKB 预训练 → ADNI 微调                           │ 利用大样本预训练，小样本精调     │
│ **多任务学习** │ 同时预测 AD + MCI + 认知下降速度                 │ 共享表征，提升小样本场景         │
│ **ATN 框架**   │ 按 A(β-amyloid) T(tau) N(neurodegeneration) 分组 │ 生物学驱动的分层预测             │
└────────────────┴──────────────────────────────────────────────────┴──────────────────────────────────┘

### 3.3 长期方向

1. **从 "预测诊断" 转向 "预测病理"**：不要预测 "会不会得 AD"，而是预测 "淀粉样蛋白何时转阳、Tau 何时扩散、萎缩何时加速"
2. **整合多队列**：ADNI (临床) + UKB (人群) + ROS/MAP (社区尸检) + AIBL (澳大利亚)
3. **时序模型**：用多次访视数据建模认知轨迹，而非单次基线预测
