## 二、标签设计的演进（最核心的变化线）

### 2.1 实验 1 (UKB): 六目标框架

**代码位置**: `src/training/run_training_v2.py` 的 `ALL_TARGETS` 字典 (L59-66)

```python
ALL_TARGETS = {
    'DM_full':  ('dementia_status', 'dementia_years', None),
    'DM_10yrs': ('dementia_status', 'dementia_years', 10),
    'DM_5yrs':  ('dementia_status', 'dementia_years', 5),
    'AD_full':  ('AD_status', 'AD_years', None),
    'AD_10yrs': ('AD_status', 'AD_years', 10),
    'AD_5yrs':  ('AD_status', 'AD_years', 5),
}
```

**标签构建逻辑** (`apply_time_window` 函数, L215-246):

```python
def apply_time_window(mydf, target_col, years_col, max_years=None):
    y = mydf[target_col].copy()
    include = pd.Series(True, index=mydf.index)

    if max_years is not None:
        y_years = mydf[years_col]
        # 窗口外转化 → y=0 (窗口内的真阴性)
        late_event = (y == 1) & (y_years > max_years)
        y.loc[late_event] = 0
        # 未转化 + 随访不足 → 删失 (排除)
        insufficient_fu = (
            (y == 0) & (y_years < 0) &
            (y_years.abs() < max_years)
        )
        include = ~insufficient_fu
    return y, include
```

**关键特点**:
- y_years 的编码方式: 负数 = 未转化（绝对值 = 随访年数），正数 = 转化年数
- 删失规则: 未转化且随访不足窗口年数的人直接排除
- UKB 的 DM 和 AD 是**新发事件**，基线人群是 40-69 岁的社区健康人群
- DM 发病率 ~1.24%，AD 发病率 ~0.57%（极低）

### 2.3 实验 4 Phase 2A: DXSUM 多窗口二分类 (MCI→Dementia)

**代码位置**: `src/training/run_adni_mci_dementia.py`

**终点重新定义** — 从 AD 变为 Broad Dementia:
```python
# build_time_targets_v2.py L92-102
is_dementia = (
    visit_diag == 3.0 or           # AD dementia
    group['DXPARK'].iloc[i] == 1.0 or  # Parkinson's dementia
    group['DXOTHDEM'].iloc[i] == 1.0   # Other dementia
)
```

**三窗口二分类标签** (3yr/5yr/10yr):
```
Dementia_Wyr = 1  ⇔  converted_to_dementia == 1 AND dementia_conversion_years ≤ W
Dementia_Wyr = 0  ⇔  converted_to_dementia == 0 AND last_followup_years ≥ W
Censored         ⇔  converted_to_dementia == 0 AND last_followup_years < W  → 丢弃
```

**删失问题严重**:
```
3yr:  丢弃 520 人 (46%) → 训练 600 人
5yr:  丢弃 620 人 (55%) → 训练 500 人
10yr: 丢弃 735 人 (66%) → 训练 385 人
```

**标签迁移** — 同一病人在不同窗口可以有不同标签:
| RID | 转化时间 | 3yr 标签 | 5yr 标签 | 10yr 标签 |
|-----|---------|---------|---------|-----------|
| 41  | 1.5 年  | y=1     | y=1     | y=1       |
| 126 | 3.0 年  | y=0     | y=1     | y=1       |
| 1108| 未转化,6.5年 | y=0 | y=0     | 删失      |

### 2.4 实验 4 Phase 2B: DXSUM 生存分析

**代码位置**: `src/training/run_adni_survival.py`

**标签从二元变为 (time, event) 对**:
```python
# run_adni_survival.py L113-116
mci['surv_time'] = np.where(mci['converted_to_dementia'] == 1,
                            mci['dementia_conversion_years'],  # 事件时间
                            mci['last_followup_years'])        # 删失时间
mci['surv_event'] = mci['converted_to_dementia'].astype(int)
```

**关键差异 vs 二分类**:
```
RID=41:   转化@1.5yr → surv(1.5, 1)       二分类: 3yr=1, 5yr=1
RID=126:  转化@3.0yr → surv(3.0, 1)       二分类: 3yr=0, 5yr=1  ← 标签翻转!
RID=1108: 未转化@6.5yr → surv(6.5, 0)     二分类: 3yr=0, 5yr=0, 10yr=删失
RID=4249: 未转化@3.0yr → surv(3.0, 0)     二分类: 3yr=0, 5yr=删失
```

**生存标签的优势**:
1. **保留全部 944 人** (排除 surv_time=0 的 176 人后)，删失者贡献部分信息
2. **连续时间** — 1.5 年和 2.9 年转化有不同的风险
3. **自动一致** — S(1) ≥ S(3) ≥ S(5) 由数学保证
4. **一个模型** — 输出完整 S(t|X)，回答任意时间点的风险

### 2.5 实验 4 Phase 2C: CDR 量表扩展

**代码位置**: `local_data/adni/build_cdr_targets_v2.py`

**终点层次结构**:
```
Primary:    首次 CDGLOBAL 恶化（分层阈值: CN 0→0.5, MCI 0.5→1.0）
Sustained:  首次恶化 + 下次访视确认
CDRSB≥1:    CDR Sum of Boxes 增加 ≥ 1.0 分
Composite:  CDGLOBAL 恶化 OR DXSUM Dementia 诊断 (仅 MCI)
```

**分层阈值** (CDR 的核心创新):
```
CN 队列  (基线 CDR=0):   事件 = CDGLOBAL ≥ 0.5  (CN → MCI 转变)
MCI 队列 (基线 CDR=0.5): 事件 = CDGLOBAL ≥ 1.0  (MCI → 痴呆水平)
```

**与 DXSUM 的本质差异**:
| 维度 | DXSUM | CDR |
|------|-------|-----|
| 终点类型 | 诊断转换 (MCI→AD Dementia) | 量表序数恶化 (CDR 0→0.5→1) |
| 覆盖人群 | MCI only | CN + MCI |
| CN→MCI 覆盖 | 无 | 有 |
| 可逆性 | 罕见 | 可逆 (150/1286 MCI 改善) |

**CDR 覆盖了 CN→MCI 这个 DXSUM 无法覆盖的阶段** — 这是关键的方法论扩展。

## 三、s01-s05 管线的统一与差异

### 3.1 管线核心流程（所有实验共享）

所有实验（UKB 复现、UKB+MRI、ADNI Phase 1、ADNI Phase 2A/2B/2C）都使用同一套 s01-s05 管线：

| 步骤 | 方法 | 参数 | 作用 |
|------|------|------|------|
| s01 | LightGBM 5-fold CV, Gain 排序 | n=500, depth=15, leaves=10 | 从全特征中选 Top 50 |
| s02 | Ward 聚类 (Spearman \|ρ\|, 阈值 0.75) | 距离=1-\|ρ\| | 去冗余，保留~18 特征 |
| s03 | 聚类后 LightGBM 重排序 | 同 s01 | 确认聚类代表的重要性 |
| s04 | Sequential Forward Selection | 贪心搜索, 早停 Δ<0.0005 | 精选 Top 10 特征 |
| s05 | 最终模型 + 5-fold CV 评估 | 校准方法因实验而异 | 独立评估泛化性能 |

### 3.2 s04 特征选择：论文代码 vs SFS（第一个重要修正）

**论文公开代码** (`AD_Training/AD_full/s04_ad_clf.py`):
```python
# 论文代码的做法: 累积 AUC (按 s03 固定顺序)
tmp_f, AUC_cv_lst = [], []
for f in my_f:              # ← 严格按 s03 排序
    tmp_f.append(f)         # ← 依次加入
    # 5-fold CV 训练+评估
    # 输出累积 AUC 曲线
```

**实际 SFS 实现** (`src/training/run_training_v2.py` 的 `run_s04_sfs`, L432-562):
```python
# SFS: 每步遍历所有剩余候选，选 AUC 增益最大的
for step in range(1, max_features):
    best_auc = -1
    for cand_idx in remaining:           # ← 遍历剩余每个候选
        trial_set = [all_features[i] for i in selected + [cand_idx]]
        auc_mean, auc_std = evaluate_feature_set(trial_set)  # 5-fold CV
        if auc_mean > best_auc:
            best_auc = auc_mean
            best_idx = cand_idx

    auc_gain = best_auc - current_auc
    if auc_gain < 0.001 and len(selected) >= TOP_N_S04:  # 早停
        break
    selected.append(best_idx)
```

**关键差异**: 论文代码是固定顺序依次加特征的"累积 AUC"，SFS 是每步重新搜索全局最优。前者只能展示"特征按重要性加入后的边际增益"，后者才是真正的贪心特征选择。所有 ADNI 实验均使用 SFS。

### 3.3 校准方法的演进（第二个重要修正）

这是跨实验变化最大的组件：

**代码位置**: `src/training/run_training_v2.py` L659-678

**代码位置**: `AD_Training/AD_full/s05_ad_full_clf.py` L55

#### ADNI Phase 1 (Phase 2A): CalibratedClassifierCV (cv=3)

**代码位置**: `src/training/run_adni_mci_dementia.py` (s05 部分)

```python
# 不切分训练集 — 用 CalibratedClassifierCV 避免浪费数据
calibrated = CalibratedClassifierCV(
    LGBMClassifier(**params),
    method='isotonic', cv=3
)
```

**为什么必须改**: ADNI MCI 仅 1,120 人，split-train-calibrate 会导致灾难:
```
外层 5-fold CV:  训练集 = 896 人
切 40% 校准集:   校准集 = 358 人, 真正训练 = 538 人
538 样本 × 358 特征 → 严重数据不足 → AUC 从 0.86 崩溃至 0.57
```

#### 生存模型 (Phase 2B/2C): 不需要概率校准

生存模型 (RSF, Cox PH) 输出的是风险函数或生存函数，不是类别概率，因此不需要 Isotonic Regression 校准。

### 4.3 ADNI Phase 1: 多表合并、特征分类

**数据来源**: ADNI IDA 门户 66 个 CSV 表格

**预处理**: `local_data/adni/preprocess_adni.py`
```
Step 1: 加载 66 个 CSV → 各表基线行筛选 (bl/sc/init)
Step 2: 人口学 + 诊断 + CDR 合并 → 核心表 (2,749 人)
```

**特征分类系统**:
```

  - 全部认知测试 (10 个): MMSE, ADAS, FAQ, GDS, NPI-Q, NEUROBAT 等
  - 全部 CDR 诊断项 (8 个): CDMEMORY, CDORIENT, CDJUDGE, CDGLOBAL, CDRSB

纳入 (358 个干净特征):
  - 人口学 (5): 年龄、性别、教育、婚姻、就业
  - 遗传 (1): APOE4_count
  - CSF (6): Aβ42, pTau, tTau 及比率
  - 血浆 (12): pTau217, Aβ42/40, NfL, GFAP
  - MRI 结构 (325): FreeSurfer v7 脑区体积/皮层厚度/面积
  - BSI (8): 全脑体积、脑室、海马
  - WMH (12): 白质高信号
  - Amyloid PET (>330): Centiloids, SUVR, Status
  - Tau PET (>330): Meta-temporal SUVR, Entorhinal SUVR
```

**缺失值处理**: **全局中位数填补** (Phase 1) vs **折内中位数填补** (Phase 2C v2)

### 4.4 ADNI Phase 2: 折内预处理（防泄漏改进）

**Phase 2C v2** 的关键改进:
```python
# Phase 2A/2B: 全局预处理
feature_df = feature_df.fillna(feature_df.median())  # 所有数据一起填补

# Phase 2C v2: 折内预处理
for train_idx, test_idx in kf.split(X, y):
    X_train = X.iloc[train_idx].copy()
    X_test = X.iloc[test_idx].copy()
    # 在训练折内计算 median，应用到测试折
    train_medians = X_train.median()
    X_train = X_train.fillna(train_medians)
    X_test = X_test.fillna(train_medians)
```

**为什么要改**: 全局填补会让测试集的信息"泄漏"到训练集（通过中位数），折内填补是更严格的评估标准。有趣的是，v2 结果反而更高，说明 v1 的泄漏并未系统性夸大性能。

## 六、评估指标的演进

### 6.1 二分类模型评估

- **AUC (ROC)**: 主指标，区分能力
- **Brier Score**: 概率校准质量
- **Sensitivity / Specificity**: Youden 最优截断点
- **AUPRC**: 不平衡数据下的排序能力（Phase 2 新增）
- **Hosmer-Lemeshow p-value**: 拟合优度（UKB 复现）

### 6.2 生存模型评估

- **Harrell's C-index**: 主指标，等同于生存框架下的 AUC
- **Time-dependent AUC** (tAUC@1yr/3yr/5yr): 各时间点的区分能力
- **Brier Score @ 特定时间**: 各时间点的校准质量
- **Cox PH HR (Hazard Ratio)**: 可解释性

### 6.3 特征消融评估

所有 ADNI 实验都包含消融分析:
```
Model A: 人口学 + 血浆/CSF 生物标记 (20 特征)  → baseline AUC
Model B: 全部干净特征 (358 特征)               → full AUC
Δ = B - A → 影像特征的独立增量
```

## 七、关键方法论文献贡献

### 7.1 论文代码与正文不一致的发现与修正

- **s04**: 论文代码做的是"累积 AUC"（固定 s03 顺序），正文描述的是 SFS（每步贪心最优）
- **APOE4**: 论文 s01 的 inner join 意外排除了 APOE4，导致论文声称的 "11 特征含 APOE4" 实际在公开代码中未实现
- **校准方法**: 论文 s05 用 CalibratedClassifierCV，Deploy 脚本用 split-train-calibrate，内部不一致

### 7.2 小样本校准方法的选择

- UKB (425K 样本): split-train-calibrate (60/40) 安全
- ADNI (1,120 样本): 必须用 CalibratedClassifierCV
- **规则**: 当 `(训练集 × 60%) < (特征数 × 10)` 时，split 不再安全

### 7.3 全队列 NaN 策略 vs 影像子集

- 全队列 + LightGBM 原生 NaN 处理 → 有效（+0.006 到 +0.184 提升）
- 仅用影像子集 → 健康志愿者偏差 + 严重过拟合 → 不可行

### 7.4 生存 vs 二分类的方法论选择

- 二分类: 简单直观，但删失浪费严重（丢 46-66% 样本）
- 生存: 保留全部样本，连续时间建模，自动一致性，但性能略低（预期内）
- **推荐**: 先做二分类建立 baseline，再做生存作为鲁棒性验证

### 7.5 CDR 作为 DXSUM 补充终点的价值

- CDR 覆盖 DXSUM 无法覆盖的 CN→MCI 阶段
- CDR 预测性能略优于 DXSUM（+0.006 到 +0.031）
- 分队列建模 (CN/MCI separate) 显著优于混合建模 (+0.036 AUC)

```
UKB 复现 (实验 1)                      ADNI Phase 1 (实验 3)
    │                                        │
    ├─ 方法学一致 ───────────────────────────┤
    │  s01-s05 LightGBM                      │
    │  Isotonic 校准 (方法不同)               │
    │                                        │

    │  ~1076 特征                             │  ~358 特征
    │                                        │
    ├─ 定位互补 ─────────────────────────────┤
    │  人群筛查 (425K, 发病率 ~1%)             │  临床预后 (1.1K, 转化率 ~27%)
    │                                        │
    │  UKB+MRI (实验 2) 架起桥梁              │
    │  证明影像在人群筛查中也有增量             │
    │                                        │
    └──────────────┬─────────────────────────┘
                   │
          ADNI Phase 2 (实验 4)
          ├─ 2A: 标签优化 (MCI→Dementia)
          ├─ 2B: 方法论升级 (生存分析)
          └─ 2C: 终点扩展 (CDR 量表)
                   │
          两者覆盖临床路径的不同阶段
          不可互相替代，不应直接比较 AUC
```

**核心洞察**: 这四个实验不是线性改良关系，而是**方法和数据在两个不同临床应用场景中的系统验证**。UKB 回答"谁需要去检查"，ADNI 回答"病情会怎样发展"。同一套 s01-s05 管线在两个场景中都有效，但标签设计、特征空间、校准方法、样本量策略都因场景不同而有针对性的调整。

### 9.8 关键发现：特征选择中的疾病特异性

结合对比矩阵，可以明确回答 "内嗅皮层/杏仁核未进入 DM_full，但对 AD 特异" 这一类问题：

**1. 海马下托 (Subiculum)**
- UKB+MRI DM_full: **进入 Top 10** (#9, 增益 +0.0013)，但排位靠后——在 DM 的全因痴呆框架中，海马下托体积是弱的贡献者
- ADNI 多个 AD/MCI 模型: FS_ST12SV（包含海马复合体的皮层下体积包）**频繁出现在 #1-2 位**
- **解释**: 下托是 Braak II 期最早的 tau 沉积区，对 AD 特异。DM 囊括血管性、代谢性痴呆等，下托萎缩的特异性被稀释

**2. 内嗅皮层 (Entorhinal Cortex)**
- CDR CN→MCI: Tau PET 内嗅皮层 SUVR **排名 #1**——在极早期（CN→MCI），内嗅皮层的 tau 沉积是最先出现的可测信号
- CDR MCI→Dementia: 内嗅皮层 SUVR **排名 #2**——到 MCI 阶段，它仍然重要
- UKB DM_full: 不出现——UKB 无 Tau PET，且 DM 不特异于 AD
- **解释**: 内嗅皮层是 Braak I 期的起点，tau 最早在此沉积。它对 AD 病理级联高度特异，对 VD、FTD 等非 AD 痴呆无信号

**3. 淀粉样蛋白 (Amyloid)**
- UKB DM_full: 无 PET 数据，无可比特征
- ADNI MCI→Dementia: 在 3yr、5yr、all-time 均进入 Top 3，但在 10yr 被 NfL 取代 #1
- **解释**: Amyloid 是 AD 的必要条件——A− MCI 几乎不会转化为 AD。但 Amyloid 沉积在临床前 15-20 年开始，到 MCI 阶段已经饱和，长期预测力不如神经退行速率 (NfL)

**4. 功能状态 (PTWORKHS) ——跨任务最一致的 #1**
- MCI→AD 5yr: #1
- MCI→Dementia all-time: #1
- MCI→Dementia Survival: #1 (消融移除时 C-index 暴跌 −0.082)
- CDR CN→MCI: #4
- UKB: 对应特征为 6142-0.3_pos (退休状态)，UKB 复现 DM_full #8

> **PTWORKHS 是最被低估的预测变量**。它不是病理标志物，而是**功能储备 (functional reserve)** 的代理变量。两个大脑病理负荷相同的 MCI 患者，仍在工作的那个有更高的认知储备和社交刺激，能更久地代偿病理损害。

**5. UKB 特有 vs ADNI 特有的特征结构**

```
UKB 模型依赖结构:                  ADNI 模型依赖结构:
  年龄 ★★★★★                        PTWORKHS ★★★★★
  用药/病史 ★★★★                    Amyloid PET ★★★★
  认知测试 (反应时间) ★★★           MRI 皮层下体积 ★★★★
  血液炎症 (CRP) ★★★                pTau217/NfL/GFAP ★★★
  家族史 (母亲AD/寿命) ★★★          APOE4 ★★★
  生活方式 (睡眠/吸烟) ★★           Tau PET (内嗅) ★★ (CN→MCI)
  海马下托体积 ★ (仅 +MRI)          WMH 白质病变 ★ (长期预测)

  共同特征: PTWORKHS/就业状态的某种编码, APOE4 (在 ADNI 中有而在 UKB 复现中缺)
```

这印证了队列定位的根本差异：UKB 做社区筛查，依赖低成本的问卷+血液检查；ADNI 做记忆诊所预后，依赖高成本的 PET+CSF+血浆+MRI。同一套 s01-s05 管线在两个特征空间中都能稳定选出有意义且可解释的特征集。
