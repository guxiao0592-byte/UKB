## 研究方案：现有模型 + Transformer影像融合 + AI-Ready数据增量

本节基于ADNI队列MCI→AD转化预测实验（s01-s05 LightGBM管线，Biomarkers+Imaging 358特征，5-fold CV AUC 0.860；特征消融Bio only 0.818→+Imaging 0.860，Δ=+0.042；SFS选定10特征中MRI结构4个+Amy PET 2个+Tau PET 1个），提出三层递进方案。

### 一、AI-Ready数据治理：从原始多模态到可信建模数据

当前ADNI实验已实现66表→基线合并→时间目标构建的预处理管线，但数据质量仍有三个瓶颈：358特征中缺失模式未系统建模（仅依赖LightGBM原生NaN处理）、血浆标志物跨检测平台（Simoa/Elecsys/Lumipulse）批次效应未校正、MCI→AD转化标签未以Aβ阳性作为必要条件。本方案提出：

**缺失机制分层建模。** 对358特征按缺失率聚类，Little's MCAR检验区分缺失类型。对随机缺失特征以MICE生成5套完整数据，对非随机缺失引入缺失指示变量作为独立预测项。此前实验已证明全队列+NaN处理范式在UKB的有效性（AD_5yrs AUC 0.667→0.851，+0.184），本方案进一步将其推广为系统的缺失机制定量建模。

**标签与生物标志物双较准。** 以"Aβ PET Centiloid≥20 + 随访临床诊断转换"双重标准重新定义MCI→AD终点，排除Aβ阴性临床AD（疑似非AD病理），降低标签噪声——SFS实验中Amyloid SUVR贡献+0.012的单步增益已证实Aβ状态的判别独立性。对血浆pTau217、NfL、GFAP三种核心标志物，按检测平台建立ComBat等值转换函数以消除批次差异。所有治理操作按Data Card规范生成全链路可追溯日志。

### 二、基于Vision Transformer的原始脑影像端到端编码

现有实验的影像特征为FreeSurfer v7分区的325个标量IDP（脑区体积、皮层厚度、面积），虽贡献了+0.042总增量（SFS选中的4个MRI特征累计增益+0.098，占全特征总增益的68%），但IDP信息密度受限于Desikan-Killiany解剖模板——原始T1影像中的纹理变异、灰白质交界微结构、亚区萎缩梯度在parcellation过程中压缩为单一标量。

本方案引入**3D Vision Transformer（ViT）**进行端到端学习：

**掩码自编码器（MAE）预训练。** 在ADNI全部2,749例T1影像上，将脑影像划分为16³体素块，随机遮挡75%，ViT编码器-解码器重建被遮挡区域。自注意力机制天然捕获跨脑区远程结构依赖——如内侧颞叶（海马-内嗅皮层）与默认模式网络在AD早期的协同萎缩模式，该信息在FreeSurfer脑区独立分割中不可得。预训练完成后冻结编码器骨干，仅在下游微调末层。

**多尺度层级化影像表征。** 从ViT浅层（第4层，局部纹理与灰白质边界）、中层（第8层，海马-杏仁核等核心AD结构形态）、深层（第12层，全局脑网络拓扑）分别提取[CLS] Token，拼接为层级化影像表征（Hierarchical Image Representation, HIR）。其病理学依据为AD沿Braak分期的跨脑区扩散——I-II期仅内嗅皮层和下托局灶萎缩，V-VI期广泛新皮层变薄，HIR的多尺度性使其并行编码不同阶段的退变模式。HIR与FreeSurfer IDP在特征层并联——HIR补充空间拓扑，IDP保留临床可解释的解剖锚点。

### 三、跨模态注意力融合：替代LightGBM特征独立排序

当前LightGBM以特征独立分裂为核心机制，SFS逐步增益曲线（0.748→0.872）证明多模态特征叠加有效，但树模型无法显式建模影像与生物标志物之间的条件依赖。本方案设计**跨模态注意力融合Transformer**：

**模态嵌入与交叉注意力。** 将三类特征——临床Token（人口学+血液标志物+APOE+功能状态）、影像Token（HIR+IDP）、治理标志Token（缺失模式+批次标签）——经线性投影映射至统一768维语义空间并加入模态类型嵌入。堆叠4层双向交叉注意力块：影像→临床注意力学习"海马萎缩程度与血浆NfL升高之间的关联强度"，临床→影像注意力学习"APOE ε4携带状态下哪些脑区的萎缩对认知下降最具判别力"。注意力权重施加L1稀疏约束以增强可解释性。融合[CLS] Token经IsotonicRegression校准输出风险概率。

**缺失模态鲁棒训练。** 为每类模态设置可学习缺失嵌入向量。训练中以p=0.3-0.5随机丢弃某类Token并以缺失嵌入替代，强制模型从部分模态推断完整表征。推理阶段天然处理任意模态组合，无需独立插补——这是UKB全队列NaN处理范式在深度网络中的严格对应。

**可解释性实现。** 将交叉注意力权重经Grad-CAM反向传播至ViT编码器，生成脑结构显著性热力图，标注对快速进展预测贡献最大的脑区（内嗅皮层、海马CA1-下托亚区、楔前叶），实现"风险数值→风险归因"的临床闭环。

### 四、增量消实验与分层部署

**四层消融设计**（5-fold CV，DeLong检验显著性）：

| 配置 | AUC预期 | Δ来源 |
|------|--------|-------|
| 基线：LightGBM SFS+IDP | 0.860 | 现有ADNI实验 |
| +AI-Ready治理（缺失建模+标签校验+跨平台校正） | 0.868-0.875 | 数据质量提升 |
| +ViT HIR（并联IDP） | 0.880-0.890 | 端到端影像编码替代手工IDP |
| +跨模态融合（Transformer替代LightGBM） | 0.890-0.905 | 多模态交互建模 |

**分层部署。** 完整模型依赖T1 MRI，适用于记忆门诊和临床试验入组。以完整模型为教师网络，知识蒸馏训练仅依赖血液标志物+认知量表+APOE的轻量学生模型（3层MLP），教师-学生AUC差距≤0.03，用于社区筛查——直接回应已有消融Δ=+0.042的启示：影像增量明确但成本高昂，分级部署最大化效率。
