# UKB-DRP 全部实验总览

> 本文档汇总从论文复现到 ADNI 外部验证的全部实验过程、数据和结果，用于梳理当前进展并决定后续实验方向。
> 生成日期: 2026-05-21

---

```

  │  数据: UKB .npz → 1076 特征, 425K 人

  │  目标: DM/AD × full/10yr/5yr (6 目标)
  │
  ├── 实验 1a: 论文特征对齐版 (138 特征)

  │

## 实验 1: UKB 论文复现

### 1.1 数据

```

│  最终特征     │ 1076 列 (含人口学、认知测试、血液检测、病史、生活方式等)     │
│  样本量       │ 502,241 人 (含所有 UKB 参与者)                            │
│  训练样本     │ ~425,159 人 (排除基线卒中和缺失随访数据后)                 │

### 1.2 方法

与论文完全一致的 s01-s05 管线，但 s04 从论文代码的累积 AUC 改为真正的 Sequential Forward Selection（与论文正文描述一致）：

```
┌───────┬────────────────────────────┬─────────────────────────────────────┐
│  步骤 │ 方法                       │ 关键参数                            │
├───────┼────────────────────────────┼─────────────────────────────────────┤
│  s01  │ LightGBM 5-fold CV 排序    │ n=500, depth=15, leaves=10          │
│  s02  │ Ward 聚类 (Spearman, 0.75) │ 输入 Top 50, 去冗余保留 ~18 特征    │
│  s03  │ 聚类后 LightGBM 重排        │ 同 s01 参数                         │
│  s04  │ SFS 贪心搜索 Top 10         │ 早停阈值 gain < 0.001               │
│  s05  │ IsotonicRegression 校准     │ 5-fold CV, 40% split-train-calibrate│
└───────┴────────────────────────────┴─────────────────────────────────────┘
```

### 1.4 关键发现

1. DM_full/10yr/5yr 基本可复现，偏差 < 0.02
2. AD_5yrs 严重偏低 (0.667 vs 论文声称 ~0.86)，原因为缺 APOE4 + 极低样本量 (306 例)
3. 论文 s04 代码是累积AUC，不是论文正文描述的 SFS
4. APOE4 被论文 s01 的 inner join 意外排除——论文声称的 "10特征含 APOE4" 实际在公开代码中未实现
5. 模型校准极好 (ECE < 0.001)，NPV > 99.5%，Brier 比传统评分好 10 倍
6. 138 特征 vs 1076 特征，AUC 仅差 0.001，特征选择稳健

```

**(C) 影像子集分析**

仅在 46,000 名有 MRI 的参与者上独立训练 s01-s04。结果发现模型严重过拟合（s04 训练集 AUC 0.895 → s05 崩溃），原因：
- 健康志愿者偏差：有 MRI 者系统性更年轻、更健康（DM_full 阳性率 0.32% vs 全队列 1.93%，差 6 倍）
- 阳性样本极少：仅 148 例痴呆
- 特征数远超阳性样本数 (2,176 >> 148)

> **方法论贡献**：证明了全队列 + LightGBM 原生 NaN 处理是唯一正确的方法论，健康志愿者偏差使得仅用影像子集训练不可行。

**(D) 选中的影像特征**

海马下托体积 (UKB IDP 26643, `volume of left hippocampal subiculum`) 在独立训练集上稳定被 SFS 选中（第 9 步，增益 +0.0013），与 AD Braak 分期中下托是最早的 tau 沉积区域一致。

### 2.4 关键发现

1. 脑 MRI 对所有 6 个目标都有统计显著的增量 (DeLong 检验 p < 0.001)
2. AD_5yrs 获益最大 (+0.184)，DM_full 获益最小 (+0.006)
3. AD 目标获益 > DM 目标：AD 有明确的神经病理基础，MRI 可直接检测
4. 海马下托是可复现的关键影像生物标志物
5. 影像子集健康志愿者偏差使得独立训练不可行

### 3.2 实验 3a: 横断面诊断预测

**方法**：s01-s05, 排除 CDR 子项和认知测试, CalibratedClassifierCV 校准。

**结果** (Biomarkers + Imaging 干净模型)：

```

│  AD vs All (CN+MCI)│   0.842  │   0.017  │ 0.093  │ 0.716  │  0.793   │

> ⚠️ AD vs CN AUC 0.935 是横断面区分（识别已确诊的 AD），不是前瞻预测。包含了诊断固有的生物学鸿沟，不等于模型在实际临床预测中的能力。

### 3.3 实验 3b: 时间窗口预测 (CN→AD/Dementia)

**目的**：按 UKB 论文的 6 目标框架，从基线 CN 预测未来发病。

**方法**：仅保留基线 CN (1,244 人), 基于 DXSUM 纵向随访追踪首次诊断转换 (CN→MCI 或 CN→AD), 构建 5yr/10yr/all-time 目标。

**结果** (Biomarkers + Imaging 干净模型)：

```
┌──────────────────────────┬──────────┬──────────┬────────┬────────┬──────────┬──────────┐
│  目标                    │ AUC (CV) │ AUC std  │ Brier  │ Sens   │ Spec     │ 事件/总   │
├──────────────────────────┼──────────┼──────────┼────────┼────────┼──────────┼──────────┤
│  AD 5yr (CN→AD)          │   0.693  │   0.072  │ 0.105  │ 0.809  │  0.526   │ 262/2379 │
│  AD 10yr (CN→AD)         │   0.677  │   0.045  │ 0.129  │ 0.841  │  0.421   │ 320/2379 │
│  AD all-time (CN→AD)     │   0.708  │   0.042  │ 0.130  │ 0.774  │  0.564   │ 340/2379 │
│  Dementia 5yr (CN→MCI/AD)│   0.752  │   0.072  │ 0.054  │ 0.653  │  0.708   │  75/1244 │

> ⚠️ CN→AD 在 5 年内只有 8 个事件 (不含经 MCI 间接转换的)。CN→MCI/AD 5yr 仅 75 例。事件极度稀疏，导致 AUC 偏低。ADNI 的 CN 受试者数量不足以支持从 CN 出发的时间窗口预测。

**与 UKB 的不可比性**：

```
┌──────────────────────┬────────────────────────────┬────────────────────────────┐
│  同一目标名称        │ UKB 中测量的               │ ADNI 中测量的               │

│  Dementia_5yrs       │ 从 425K 健康人中找 0.20%   │ 从 1.2K CN 中找 6%          │
│  结论                │ 筛查工具                   │ 预后工具, 不可比             │

### 3.6 ADNI 关键发现

1. **正确目标纠正**：ADNI 的 CN→AD 预测几乎不可行 (5yr 仅 8 例)，MCI→AD 才是正确的预测任务 (AUC 0.86)
2. **UKB 和 ADNI 不可直接比较 AUC**：UKB 做人群筛查 (发病率 0.08-1.24%)，ADNI 做临床预后 (转化率 23-27%)
3. **Amyloid PET 是最强的单一影像特征**，pTau217 是最强的血浆生物标记
4. **PTWORKHS (就业状态) 排名第一**：功能状态是比认知测试更客观的衰退指标
5. **小样本必须用 CV 校准**：split-train-calibrate 在 1,120 人样本下崩溃 (AUC 0.57)，CalibratedClassifierCV 恢复到 0.86
